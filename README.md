A program that draws a 1024x1024 newspaper poster summing up Wednesday 18 November 2026 in one image: a dated header plus six story panels (US–Iran Gulf strikes, the Kerch bridge span falling, the Xi–Putin meeting in Shenzhen ahead of the Trump trilateral, Peltola winning the Alaska Senate seat, Ebola cases doubling in DR Congo, and Category 5 Cyclone Xavier hitting the Cook Islands), each with a hand-drawn pictogram, a headline and one factual sub-label. Pure Python standard library, no network, byte-identical output on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024, under 1 MiB).
